# Тактичний Урбаніст — v7

## Виправлення та покращення
- Розподіл секторів на міській карті тепер коректно підтримує 1–6 гравців. Раніше індекс власника обмежувався 4, через що кольоровий розподіл при 5–6 гравцях був некоректним.
- Тест карти перевіряє рівномірність призначення 12 секторів для всіх конфігурацій 1–6 гравців.
- Текст у панелі сектора уточнює, що власність і будівлі поки умовні на карті та не зберігаються як окремий серверний стан території.
- Додано запуск `./gradlew` для Linux/macOS: використовує локальний Gradle, або завантажує Gradle 8.7, якщо Gradle не встановлений. Додано Windows launcher `gradlew.bat` (він вимагає локально встановлений Gradle).

## Відомі обмеження
- Секторна власність ще не серверна/збережена: карта розподіляє райони умовно між гравцями.
- Будівлі показуються маркерами на мапі за загальним лічильником гравця, а не як збережені об'єкти в конкретному районі.
- Для реального захоплення територій, атак по районах і локального будівництва потрібна наступна серверна модель секторів.

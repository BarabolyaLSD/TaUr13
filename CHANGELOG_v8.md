# Тактичний Урбаніст — v8

## Карта стала частиною серверного стану гри
- Додано серверний стан 12 секторів: ID, власник та локальні лічильники промисловості/армії/оборони.
- На старті партії сектори розподіляються рівномірно між гравцями (різниця не більше одного сектора для 1–6 гравців).
- Вибір сектора на карті впливає на панель будівництва: будувати/відновлювати можна лише у власному секторі.
- Запит будівництва передає ID сектора; сервер повторно перевіряє власника, а не довіряє UI.
- Будівлі та відновлення додаються до конкретного сектора; візуальні маркери відображають секторний стан із серверного view.
- Після карт, що руйнують будівлі, секторні лічильники синхронізуються з ресурсами гравця, щоб карта не показувала знищені об'єкти.
- При новій партії/перезапуску секторальний стан очищується та розподіляється заново.

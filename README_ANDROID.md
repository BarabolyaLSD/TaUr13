# Тактичний урбаніст — Android-додаток

Один додаток для всіх: **«Створити гру»** запускає сервер на телефоні-господарі (у фоні), **«Приєднатися»** відкриває гру іншого телефона. Усередині — WebView із тією самою сторінкою, що й у мережевій версії. Інтернет не потрібен, лише спільна Wi-Fi мережа або точка доступу одного з телефонів.

> Важливо: APK у цьому проєкті **не зібраний готовим файлом** — для збірки потрібен Android SDK. Нижче три способи отримати його. Ігрове ядро й сервер перевірені на JVM (див. «Тести»), а Android-оболонка (меню, служба, WebView) компілювалась лише проти заглушок API й **не запускалась на справжньому телефоні**.

## Як отримати APK

### Спосіб 1 — GitHub Actions (без Android Studio)
1. Створіть порожній репозиторій на github.com і завантажте в нього вміст цієї папки (разом із прихованою `.github`).
2. Відкрийте вкладку **Actions → Build APK**. Збірка запуститься сама (або «Run workflow»).
3. Через 3–6 хвилин відкрийте завершений запуск і завантажте артефакт **tactical-urbanist-apk** — усередині `app-debug.apk`.
Workflow також запускає тести ігрового ядра: якщо вони впадуть, збірка зупиниться.

### Спосіб 2 — Android Studio
1. Встановіть Android Studio, **File → Open** і виберіть цю папку.
2. Дочекайтесь Gradle Sync (потрібен інтернет для завантаження компонентів).
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Спосіб 3 — командний рядок
Потрібні JDK 17, Android SDK (платформа 34) і Gradle 8.7:
```
gradle assembleDebug
```

## Встановлення на телефон
Скопіюйте `app-debug.apk` на телефон, відкрийте його й дозвольте «Встановлення з невідомих джерел» для файлового менеджера/браузера. Це debug-збірка, підписана тимчасовим ключем: для особистого тестування цього достатньо.

## Як користуватися
- **Господар:** «Створити гру» → дозвольте сповіщення (Android 13+) → з'являться адреси на кшталт `http://192.168.1.25:8000` → «Відкрити гру».
- **Гравці:** «Знайти ігри в мережі» (знаходить господаря автоматично) або введіть адресу вручну → «Підключитися за адресою». Підходить і звичайний браузер за тією ж адресою.
- Без роутера: увімкніть точку доступу на телефоні-господарі, підключіть інші телефони до неї, адреса зазвичай `192.168.43.1:8000`.
- Поки сервер працює, у шторці висить сповіщення (так Android не вбиває службу). Зупинити можна кнопкою «Зупинити сервер».
- Назад із гри — запитає підтвердження виходу. Сесія гравця зберігається, тож можна повернутися в гру.

## Що всередині
- `app/src/main/java/ua/urbanist/core/` — правила гри, боти, Автоматичний Сусід, HTTP-сервер, пошук у мережі. Чиста Java 8, без залежностей.
- `app/src/main/java/ua/urbanist/app/` — Android: `MainActivity` (меню), `GameService` (фоновий сервер), `GameActivity` (WebView).
- `app/src/main/assets/web/` — клієнтська сторінка й зображення.
- `jvm-tools/` — запуск того ж сервера на ПК та самотести ядра.

## Тести (на ПК, потрібен JDK 17+)
```
mkdir out
javac -encoding UTF-8 -d out app/src/main/java/ua/urbanist/core/*.java jvm-tools/ua/urbanist/tools/*.java
java -cp out ua.urbanist.tools.SelfTest            # правила + 2500 партій ботів, інваріанти
python3 tests/test_http_java.py                    # багатоклієнтні партії через HTTP (потрібен JCP=out)
java -cp out ua.urbanist.tools.Main --port 8000 --assets app/src/main/assets/web   # сервер на ПК
```
Для HTTP-тесту: `JCP=out ASSETS=app/src/main/assets/web python3 tests/test_http_java.py`.

## Відомі обмеження
- Android 14+ вимагає тип служби `dataSync`; Android 15 обмежує такі служби кількома годинами на добу — для ігрових сесій цього вистачає.
- Деякі виробники (Xiaomi, Huawei, Samsung) агресивно вимикають фонові програми: для додатка виберіть у налаштуваннях батареї «Без обмежень».
- Пошук ігор використовує UDP-широкомовлення (порт 47321); деякі роутери його блокують — тоді вводьте адресу вручну.
- Збірка release-версії для Google Play вимагає власного ключа підпису (тут не налаштований).

Цей редизайн перевірено синтаксично та тестами ядра/HTTP. Візуальний тест у реальному Android-пристрої ще не виконаний.

## Інтерактивна міська карта (v5)
- Ігрова сцена в горизонтальному режимі займає весь екран; фонове місто та SVG-території рухаються й масштабуються синхронно.
- На мапі є 12 секторів із неоновими межами, назвами, кольорами власників та вибором сектора.
- Вибір сектора відкриває інформаційну панель і переводить фокус карти до нього.
- Камера: перетягування одним пальцем, pinch-зум, колесо миші, кнопки +/− та скидання огляду.
- Будівлі гравця відображаються на його секторах маркерами промисловості, війська та оборони, залежно від актуальних ресурсів.
- **Поточне обмеження:** власність на сектори розподіляється для візуалізації відповідно до кількості гравців; захоплення/окупація секторів як окрема серверна механіка ще не реалізована. Розміщення будівель на конкретному секторі також поки візуальне, а не серверно збережене.
- Статичні перевірки карти: `node tests/map_static_test.js`.

### Збірка APK через GitHub Actions

У репозиторії використовується встановлений Gradle через GitHub Actions, а не локальний `gradlew`. Не запускайте `chmod +x gradlew`, якщо файл `gradlew` відсутній. В Actions workflow встановлює Gradle 8.7 і виконує `gradle assembleDebug --no-daemon`.

Preview of sector boundaries (static concept overlay, not a live APK screenshot): `docs/map_overlay_preview_v6.png`.

## Gradle launcher added in v7

Use `./gradlew assembleDebug` on Linux/macOS (or `gradlew.bat assembleDebug` on Windows). The launcher uses a locally installed Gradle if available; otherwise it bootstraps Gradle 8.7 on Linux/macOS using curl or wget and unzip. GitHub Actions still installs Gradle 8.7 explicitly.

## v8 — серверні сектори міста

Карта тепер синхронізується із серверним станом 12 секторів. Кожен сектор містить власника та локальні лічильники промисловості/армії/оборони. На старті сектори розподіляються між 1–6 гравцями рівномірно. У фазі будівництва вибраний сектор є ціллю: сервер дозволяє будувати або відновлювати лише у власному секторі й перевіряє ID власності. Маркери будівель відображають локальний секторний стан, а після карт-руйнувань він синхронізується з лічильниками гравця.

Захоплення територій та повноцінна ізометрична 3D-сцена — наступні окремі функції; вони не входять у v8.

## v9 rule correction
Стартовий стан гравця: 1 енергія, 0 промисловості, 0 війська, 0 оборони. Початкова промисловість не генерує енергію до її будівництва.

## v10 — attacks by district / territory capture
- Attacks are aimed at a selected district of the opponent, so damage is reflected in that sector's building markers and ownership state.
- Spy, General, Disaster, and Sabotage affect structures in the selected sector. Economic Crisis remains global energy loss.
- An empty sector can be captured only by an attacker with at least one army unit; the defender must still own another sector. This is the new v10 rule.
- Capture changes the authoritative sector owner, which updates the map colors and who may build there.
- v10 validation: Java compilation, SelfTest, district-map static tests, inline JavaScript syntax, and HTTP integration completed successfully in the development container. Android APK and real-device visual testing were not performed.

## v11 — корекція секторної атаки Генерала
У секторній логіці карта Генерал тепер знищує 1 військо, якщо воно є; інакше завдає 2 втрат промисловості. Додаткова втрата оборони застосовується за наявності оборонної споруди. Перевірено Java SelfTest, статичні тести карти, синтаксис вбудованого JavaScript та HTTP інтеграцію (921 запит, 0 помилок). Android APK/реальний пристрій не перевіряли.
